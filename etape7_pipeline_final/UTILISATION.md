# Comment utiliser le site

**Lien du site :** _(à compléter avec l'URL donnée par Streamlit Cloud,
ex. `https://appel-offre-ats-oi.streamlit.app`)_

## Le site ne s'affiche pas / écran "Zzzz" ?

Le site s'endort tout seul s'il n'a pas été visité depuis quelques jours.
Ce n'est pas un bug — il suffit de le réveiller :

1. Ouvrez le lien du site.
2. Si vous voyez un écran avec écrit quelque chose comme *"This app has
   gone to sleep due to inactivity"*, cliquez sur le bouton
   **"Yes, get this app back up!"** (ou juste "Wake up").
3. Patientez environ 30 secondes à 1 minute pendant qu'il redémarre.
4. La page se recharge automatiquement — le site est utilisable normalement.

Ça n'arrive jamais en cours d'utilisation, seulement si personne n'a
ouvert le site depuis un moment. Une fois réveillé, il reste actif tant
que quelqu'un l'utilise régulièrement.

## Utilisation normale

- **Onglet "🎯 Trier"** : une offre à la fois, cliquez "👍 Intéressant" ou
  "👎 Pas intéressant".
- **Onglet "📋 Historique"** : retrouver ce que vous avez déjà trié.
- **Onglet "🔑 Mots-clés"** : ajouter/retirer les mots-clés recherchés.
- Bouton **"🔍 Lancer la recherche"** (dans le menu de gauche) : va
  chercher les nouveaux appels d'offres — à faire de temps en temps
  (une fois par jour suffit largement), pas besoin à chaque visite.
